## 🧠 Descripción del proyecto

Este proyecto documenta el flujo completo de procesamiento de datos aplicado a un conjunto de ventas ficticias. Utilizando Python, Pandas, Matplotlib y Seaborn, se desarrollaron las siguientes etapas:

- Carga y exploración inicial del dataset
- Limpieza de valores nulos y duplicados
- Conversión de tipos de datos
- Estandarización de texto
- Feature engineering: creación de columnas como `Ingreso_Total`, `Año`, `Mes`, `Día_Semana`
- Visualizaciones: histogramas, boxplots, gráficos de barras y líneas
- Reflexión sobre decisiones tomadas y próximos pasos
